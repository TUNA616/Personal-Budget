# 내 가계부 분석기

은행·카드 거래내역 파일을 올리면 수입/지출을 자동 분류하고, 저축률과 줄일 수 있는 지출을 진단해 주는 **단일 HTML 파일** 가계부 분석기입니다.

서버가 없습니다. `index.html` 하나를 브라우저로 열면 그게 전부이고, 거래 데이터는 그 브라우저 밖으로 나가지 않습니다.

## 쓰는 법

1. [`index.html`](index.html)을 내려받습니다. (Releases의 파일을 쓰거나, 이 저장소에서 Raw 저장)
2. 브라우저로 파일을 엽니다. (Chrome, Edge, Safari, Firefox 최신 버전)
3. 비밀번호를 정합니다. 이 비밀번호로 모든 데이터가 암호화되어 브라우저에만 저장됩니다.
4. **불러오기·입력** 탭에서 은행/카드사에서 받은 거래내역 파일(`.xlsx`, `.csv`, 엑셀형 `.html`)을 올립니다.

처음이라면 **분석·솔루션** 탭의 "샘플 데이터로 체험하기"로 기능을 먼저 둘러볼 수 있습니다. 샘플은 설정 탭에서 언제든 지울 수 있습니다.

### 거래내역 받는 곳

- **시중은행**: 인터넷뱅킹 → 조회 → 거래내역조회 → 엑셀(또는 파일) 저장
- **인터넷은행**: 앱 → 계좌 → 거래내역 → 내역 내보내기 / 메일 받기 (암호 걸린 파일은 먼저 풀어서 저장)
- **카드사**: 홈페이지 → 이용내역 조회 → 엑셀 다운로드 (승인내역보다 "이용대금명세서/매입내역"이 정확)

카드 내역과 은행 내역을 둘 다 올리면, 은행의 "카드대금 출금"은 중복으로 보고 자동 제외합니다.

## 기능

- **자동 열 인식** — 은행·카드사별로 다른 열 이름(거래일시/이용일자, 출금액/찾으신금액, 가맹점명/적요 등)을 자동으로 찾아 연결합니다. 틀리면 화면에서 직접 바꿀 수 있습니다.
- **카테고리 자동 분류** — 가맹점명 키워드 약 200개 규칙 기반. 직접 고치면 "규칙으로 저장"해 다음부터 자동 적용됩니다.
- **내 계좌 간 이동 제외** — 본인 이름/계좌 단서/이체 키워드, 증권계좌 입출금, 그리고 서로 다른 내 계좌 사이에 같은 금액이 오간 거래를 자동으로 짝지어 수입·지출에서 뺍니다. 적금 납입을 "지출"로 세는 문제를 피하기 위한 것입니다.
- **지출 진단** — 저축률 신호등, 목표 저축률까지 줄일 금액과 카테고리별 추천 예산, 정기결제·구독 탐지, 소액 결제 누적, 배달 빈도, 급증한 카테고리, 심야 결제, 50/30/20 비교.
- **투자 손익** — 보유 종목의 평가손익. 시세 API 키(선택)를 넣으면 자동 조회, 없으면 현재가를 직접 입력합니다.
- **CSV 내보내기 / 암호화 백업**

### 지원 파일 형식

`.xlsx`, `.csv`, `.tsv`, 탭/쉼표 구분 텍스트, 엑셀이 만든 HTML 표(`.xls`로 받아지는 경우가 많습니다), 그리고 엑셀에서 복사한 표 붙여넣기.

구형 바이너리 `.xls`는 지원하지 않습니다. 엑셀에서 열어 `.xlsx`나 CSV로 다시 저장해 주세요.

## 보안 구조

- 모든 처리는 이 파일 안에서만 일어납니다. 서버·클라우드·분석 도구가 없습니다.
- 저장 데이터는 **AES-256-GCM**으로 암호화됩니다. 키는 비밀번호에서 **PBKDF2-SHA256 60만 회**로 유도하고 추출 불가(`extractable: false`) 상태로 메모리에만 둡니다. 비밀번호 자체는 저장하지 않습니다.
- 기준보다 약한 반복 횟수로 만들어진 금고(예: 조작된 백업 파일)는 잠금 해제 시 현재 기준으로 다시 암호화합니다.
- CSP(`<meta http-equiv="Content-Security-Policy">`)로 외부 통신을 시세 API 3곳(`apis.data.go.kr`, `finnhub.io`, `api.twelvedata.com`)으로만 제한했습니다. 그 외 주소로는 브라우저가 전송을 막습니다.
- 시세 조회 때는 **종목코드와 API 키만** 보냅니다. 보유 수량·거래내역은 보내지 않습니다.
- 가맹점명 등 외부 문자열은 `innerHTML` 없이 `createElement`/텍스트 노드로만 그려서 스크립트 삽입을 막습니다.
- 설정한 시간 동안 조작이 없으면 자동으로 잠깁니다. (기본 10분)

### 주의사항

- **비밀번호를 잊으면 복구할 수 없습니다.** 설계상 어디에도 저장되지 않습니다. 설정 탭에서 주기적으로 "암호화 백업"을 받아 두세요.
- 브라우저의 사이트 데이터·캐시를 지우면 저장된 금고도 함께 사라집니다. 백업이 유일한 복구 수단입니다.
- **공용 PC에서는 쓰지 마세요.**
- 원본 거래내역 파일은 가져온 뒤 지우거나 암호화된 곳에 보관하는 걸 권합니다.
- CSV 내보내기는 **암호화되지 않은 평문**입니다. 공유 폴더·메신저에 올리지 마세요.
- 웹에 올려서 쓰는 경우, 브라우저 저장소는 출처(origin)별로 묶입니다. 같은 도메인에 다른 페이지가 함께 올라가 있으면 그 페이지들도 암호화된 금고 데이터에 접근할 수 있습니다. 파일을 내려받아 로컬에서 여는 쪽이 설계 의도에 맞습니다.

## 한계

- 분석은 규칙 기반의 일반적인 가이드입니다. 투자·대출 등 중요한 재무 결정은 전문가와 상의하세요.
- 자동 분류와 "내 계좌 간 이동" 판단은 완벽하지 않습니다. 결과를 한 번 훑어보고 틀린 항목은 거래내역 탭에서 직접 바꿔 주세요. 수동으로 바꾼 항목은 자동 분류가 덮어쓰지 않습니다.
- 시세 API 무료 요금제는 분당 호출 제한이 있고, 국내 종목 지원 여부가 요금제에 따라 다릅니다.

## 개발

빌드 과정이 없습니다. `index.html` 하나를 편집하고 브라우저에서 새로 고치면 됩니다. 의존성, 패키지 매니저, 번들러가 모두 없습니다.
